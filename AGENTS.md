## Development

- Use background mode when starting the local dev server:

```bash
astro dev --background
```

- Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.
- Prefer the project scripts in `package.json` for routine local checks and previews.

## AI workflow and edit policy

- Do not make automatic code or content changes without explicit user approval.
- Ask before editing files, refactoring code, or creating new project assets.
- Keep changes minimal, targeted, and clearly tied to the user request.
- If there is ambiguity, explain the proposed change and wait for confirmation.
